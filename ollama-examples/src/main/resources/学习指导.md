# ollama-examples 模块学习指导

## 模块概述

这是演示如何用 **Ollama 在本地运行开源大模型**（如 Llama 3.1）并通过 LangChain4j 调用的示例。它进"必要学习"清单的原因是：**不需要 OpenAI 等付费 API Key**，在本地就能跑通对话、流式，是零成本练手和离线开发的最佳选择——对国内开发者尤其友好。

> 这一课不是让你"换用本地模型"，而是理解"LangChain4j 对接哪种模型只是换一个 Model 类/改 baseUrl 的事"，模型可插拔。本地 Ollama 让你无需密钥即可反复试验。

## 总体在教什么

- 让 LangChain4j 连接本地跑的 Ollama（`OllamaChatModel`、`OllamaStreamingChatModel`）
- 配置 `baseUrl` 指向本机 Ollama 服务（默认 `http://localhost:11434`）
- 选择本地已拉取的模型名（`modelName`）
- 通过 Testcontainers 自动拉起一个 Ollama Docker 容器来测试
- 结构化的 JSON 输出（让本地模型也输出固定结构）
- 理解"本地模型 vs 云端模型"的接入区别

## 学习路径（按优先级从高到低，逐一定义）

| 优先级 | Java 类 | 讲什么 | 是否必须学习 |
|--------|---------|--------|:---:|
| 1 | `utils/AbstractOllamaInfrastructure.java` | **先看它**：解释连接本机 Ollama（`OLLAMA_BASE_URL`）还是用 Testcontainers 起容器，是理解整个模块环境的钥匙。 | 是 |
| 2 | `OllamaChatModelTest.java` | 核心用法：构建 `OllamaChatModel`（baseUrl + modelName）做对话，并演示 JSON 结构化输出。 | 是 |
| 3 | `OllamaStreamingChatModelTest.java` | 流式对话：边生成边输出（打字机），与云端流式用法一致。 | 是 |
| 4 | `utils/LangChain4jOllamaContainer.java` | Testcontainers 容器：自动起 Ollama 容器并 `ollama pull` 拉模型，供测试用。 | 否（环境搭建，读懂用途即可） |
| 5 | `utils/OllamaImage.java` | Ollama 镜像名管理与本地复用逻辑。 | 否（支撑类） |

## 学习建议

- **先看 `AbstractOllamaInfrastructure`** 理解两种连接方式，再读两个测试类。
- **动手前提**：要么本机装好 Ollama 并 `ollama pull llama3.1`，要么能跑 Docker/Testcontainers。条件不满足时就纯读代码。
- **抓住"可插拔"思想**：把 `OllamaChatModel` 换成 `OpenAiChatModel`，其余代码几乎不变——这就是 LangChain4j 统一接口的优势，也是面试常问的"如何切换模型厂商"。
- 本地模型能力弱于云端，但用来学 ApiService/工具/RAG 思路完全够用，且零成本无限测试。
- 这一课能让你在**没有 OpenAI Key**的情况下独立完成所有练习，强烈建议搭建好本地环境配合其他模块学习。
