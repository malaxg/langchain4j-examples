# rag-examples 模块学习指导

## 模块概述

这是 LangChain4j 官方 **RAG（检索增强生成）专题模块**，也是面试高频考点。RAG 解决的核心问题是：**LLM 不知道你企业的私有知识**（产品手册、条款、报表、票务……），通过"先检索相关资料，再让模型基于这些资料回答"，让答案有依据、可追溯、减少幻觉。

本模块按 4 个层级组织，从"一行 API 搞定"到"看懂底层手写"，**务必按层顺序学**：

- `_1_easy`：最简单的低代码 RAG
- `_2_naive`：朴素 RAG（自己动手搭一遍核心链路）
- `_3_advanced`：10 个高级 RAG 技巧（查询压缩、路由、重排、元数据过滤、多检索器、Web 搜索……）
- `_4_low_level`：低层 API 手写 RAG，理解原理

## 总体在教什么

- RAG 全链路：读取文档 → 切块（DocumentSplitter）→ 向量化（EmbeddingModel）→ 存向量库（EmbeddingStore）→ 检索 → 交给 LLM 回答
- 各种让检索更聪明的技巧（重排、路由、元数据、查询压缩等）
- 如何返回"用了哪些资料"（可追溯）
- 底层原理：脱离高级抽象，自己控制每一环

## 学习路径（按优先级从高到低，逐一定义）

| 优先级 | Java 类 | 讲什么 | 是否必须学习 |
|--------|---------|--------|:---:|
| 0 | `shared/Utils.java` | 公共工具：构建模型、切块、入库、聊天模型等复用函数。**先扫一眼它**，后面示例大量复用它，看懂它事半功倍。 | 是 |
| 0 | `shared/Assistant.java` | 公共 AI 服务接口：带检索器的聊天接口（RAG 的回答入口）。 | 是（配合 Utils 看） |
| 1 | `_1_easy/Easy_RAG_Example.java` | **入门第一课**：以"最少的代码"实现完整 RAG，建立"切块→入库→检索→回答"的整体印象。 | 是 |
| 2 | `_2_naive/Naive_RAG_Example.java` | 朴素 RAG：不依赖高级封装，手把手走一遍 RAG 的每一步，彻底搞懂数据流。 | 是 |
| 3 | `_3_advanced/_01_Advanced_RAG_with_Query_Compression_Example.java` | 查询压缩：让模型先把"指代不清的多轮问题"压缩成独立问题，再接检索。多轮 RAG 必备。 | 是 |
| 4 | `_3_advanced/_02_Advanced_RAG_with_Query_Routing_Example.java` | 查询路由：根据问题类型路由到不同的检索引擎/数据源。 | 是 |
| 5 | `_3_advanced/_03_Advanced_RAG_with_ReRanking_Example.java` | 重排（ReRanking 模型）：检索出 Top-N 后用重排模型精排，显著提升准确率。 | 是 |
| 6 | `_3_advanced/_04_Advanced_RAG_with_Metadata_Example.java` | 元数据：给文档块附加元数据（作者、日期、类型），让检索结果更精准。 | 是 |
| 7 | `_3_advanced/_05_Advanced_RAG_with_Metadata_Filtering_Examples.java` | 元数据过滤：检索时带条件（如"只要 2024 年的文档"）。生产高频用法。 | 是 |
| 8 | `_3_advanced/_09_Advanced_RAG_Return_Sources_Example.java` | 返回引用来源：让回答能给出"依据了哪些文档"，增强可信度与可审计性。 | 是 |
| 9 | `_3_advanced/_07_Advanced_RAG_Multiple_Retrievers_Example.java` | 多检索器：同时从多个检索源取上下文。 | 是 |
| 10 | `_3_advanced/_10_Advanced_RAG_SQL_Database_Retreiver_Example.java` | 数据库检索器：直接从 SQL 数据库取数作为上下文（Text-to-SQL 思路）。 | 是 |
| 11 | `_3_advanced/_06_Advanced_RAG_Skip_Retrieval_Example.java` | 跳过检索：当问题无需检索时（如闲聊）跳过 RAG，省 token。 | 否 |
| 12 | `_3_advanced/_08_Advanced_RAG_Web_Search_Example.java` | Web 搜索检索器：让 Agent 能联网检索最新信息。了解即可。 | 否 |
| 13 | `_4_low_level/_01_Low_Level_Naive_RAG_Example.java` | 低层 API：不借助高级检索抽象，手动控制 embedding + 相似度检索 + 组装上下文。理解原理必读。 | 是 |

## 学习建议

- **顺序**：先 `shared`，再 `_1_easy` → `_2_naive`，建立原理后进入 `_3_advanced`。
- **`_2_naive` 是"原理之根"**：把它每一步读透，后面的高级技巧都是在它基础上加优化。
- **`_3_advanced` 每个文件都是独立的**，面试问哪个点就回来补哪个（重排、路由、元数据过滤是高频）。
- **`_4_low_level` 放到最后**：它展示 LangChain4j 内部怎么实现 RAG，读完对框架理解加深一层，但前期不需要。
- 学完本模块 + `customer-support-agent-example`，RAG 的"应用层 + 原理层"就都齐了，足以应对面试中绝大多数 RAG 问题。
