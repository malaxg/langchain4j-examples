# other-examples 模块学习指导

## 模块概述

这是 LangChain4j 的**通用示例合集**，与 `tutorials` 内容互补但更零散。它不按难度线性编排，而是把官方文档中各种常用功能拆成独立示例：记忆、持久化记忆、工具、动态工具、流式、检索引擎（RAG）、文档加载、Embedding 向量、AutoModeration（自动审核）、结构化提示词、代理（Proxy）等。

**它的定位**：当你学完 `tutorials` 掌握了主线后，用本模块来"补齐盲区"——每个文件都是对应知识点的独立参考。遇到不懂的功能，先来这里找对应示例。

## 总体在教什么

- AI 服务的各种变体：记忆、持久化、工具、流式、检索、自动审核
- 与文档对话和文档加载（DocumentLoader）
- Embedding 向量：模型、调用方式、内存存储、文本分类
- 结构化提示词模板（StructuredPrompt）
- 提示词模板、流式、记忆、工具的"多版本参考"

## 学习建议

- 本模块文件多，**不要按顺序刷**，而是"缺什么补什么"。
- 主线建议：`SimpleService → OtherService → Memory(两种) → Tools(两种) → Streaming → Retriever → ChatWithDocuments → DocumentLoader → Embedding`。
- `embedding` 子目录选一个模型示例看懂向量概念即可，其余厂商大同小异。
- 持久化（MapDB）、AutoModeration、Proxy 属于进阶/特定场景，面试和实战前期可跳过。
