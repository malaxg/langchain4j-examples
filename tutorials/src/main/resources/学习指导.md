# tutorials 模块学习指导

## 模块概述

这是 LangChain4j 的**官方入门教程模块**，也是整个项目最优先学习的模块。它用 13 个独立的 Java 文件，从"跑通第一次对话"开始，循序渐进地覆盖了 LangChain4j 的核心概念：模型构建、参数配置、提示词模板、流式输出、记忆、少样本提示、AI 服务、工具调用、文档对话（基础 RAG）。

每个文件都是一个独立的 `main`，可单独运行。**先跑通再理解，是本模块唯一的诀窍。**

## 总体在教什么

- 如何构建聊天模型（`ChatModel`）并完成一次对话
- 如何配置模型的温度、超时、日志等参数
- 提示词模板（`{{变量}}` 占位）与结构化提示词
- 流式输出（打字机效果）
- 对话记忆与"按用户隔离"的多份记忆
- 少样本提示（Few-Shot）让模型模仿输出格式
- **AI 服务（AiService）**——LangChain4j 最强大的工程化抽象
- 工具调用（方法级 Tool）与动态工具
- 与文档对话（入门级 RAG）

## 学习路径（按优先级从高到低，逐一定义）

| 优先级 | Java 类 | 讲什么 | 是否必须学习 |
|--------|---------|--------|:---:|
| 1 | `_00_HelloWorld.java` | 整个框架的"你好世界"：构建模型 + 发一条消息 + 打印回答。先跑通它建立信心。 | 是 |
| 2 | `_01_ModelParameters.java` | 模型参数配置：temperature（随机性）、timeout（超时）、logRequests/logResponses（请求/响应日志）。学排查问题。 | 是 |
| 3 | `_03_PromptTemplate.java` | 提示词模板：`{{变量}}` 占位符、结构化提示词对象，让提示词可复用、可维护。 | 是 |
| 4 | `_04_Streaming.java` | 流式输出：模型一边生成一边输出，体验打字机效果，是真实聊天应用的基础。 | 是 |
| 5 | `_05_Memory.java` | 对话记忆：让 AI 记住多轮上下文，否则每次对话都是"失忆"的。 | 是 |
| 6 | `_06_FewShot.java` | 少样本提示：先给几个输入/输出示例，再让模型按示例风格回答，效果优于口头要求。 | 是 |
| 7 | `_08_AIServiceExamples.java` | **核心中的核心**。AI 服务：声明式接口 + 自动解析成枚举/数字/日期/POJO/List，注入记忆。内含多个独立示例类。 | 是 |
| 8 | `_10_ServiceWithToolsExample.java` | 工具调用：让模型调用你的 Java 方法，是 Agent 的雏形。 | 是 |
| 9 | `_11_ServiceWithDynamicToolsExample.java` | 动态工具：运行时分批提供工具列表，比静态工具更灵活。 | 是 |
| 10 | `_12_ChatWithDocumentsExamples.java` | 与文档对话（入门 RAG）：把文档切块入库再检索，是后续 rag-examples 的前奏。 | 是 |
| 11 | `_09_ServiceWithPersistentMemoryForEachUserExample.java` | 持久化记忆 + 按用户隔离：把记忆落盘到 MapDB，重启不丢；进阶内容。 | 否 |
| 12 | `_02_OpenAiImageModelExamples.java` | 图像生成模型（ImageModel），与对话无关，兴趣了解。 | 否 |
| 13 | `ApiKeys.java` | 从环境变量读取 API Key 的辅助类。无需细读，知道它是"全局密钥提供者"即可。 | 否 |
| 13 | `Model.java` | 共享模型类：集中构建了 `MODEL`（Chat）与 `STREAM_MODULE`（流式）供各示例复用。属于本次重构产生的辅助类，了解引用关系即可。 | 否 |

## 学习建议

- **先跑 `_00`**：配好 `OPENAI_API_KEY` 环境变量后运行，看到回答即算入门。
- **重点是 `_08`**：AI 服务是企业开发最常用的抽象，务必逐个小示例看明白（尤其结构化输出与记忆）。
- **`_10`/`_11`** 是通向 Agent/工具调用的桥，学完即可进入 `customer-support-agent-example`。
- 可选内容（`_02`/`_09`）和辅助类（`ApiKeys`/`Model`）了解即可，不影响主线。
