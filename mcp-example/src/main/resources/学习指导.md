# mcp-example 模块学习指导

## 模块概述

这是 **MCP（Model Context Protocol）** 工具接入示例，也是当前 AI 开发的新标配。MCP 是 Anthropic 提出的开放协议，统一了"外部工具如何接入大模型"的标准——你可以用同一套方式接入出行、订餐、GitHub、数据库等各种第三方服务，而不必为每个服务写专用集成代码。

本模块演示在一个 Agent 里通过 MCP 注册远程工具（HTTP/SSE）和本地工具（stdio 子进程）两种方式，然后让模型调用这些外部工具。

> 这是你"必要性"清单里的必修项——MCP 在 2025-2026 的 AI 工程化中快速普及，面试和实战都会遇到。

## 总体在教什么

- MCP 是什么、为什么它能让工具接入标准化
- 用 HTTP/SSE 方式连接远程 MCP 服务器（`.sseUrl(...)`）
- 用 stdio 方式启动本地子进程连接 MCP 服务器（`.command(...)`）
- 把 MCP 提供的工具注册（`McpToolProvider`）并注入 AiService，让 Agent 能调用
- 如何在本地起一个 MCP 服务器配合测试

## 学习路径（按优先级从高到低，逐一定义）

| 优先级 | Java 类 | 讲什么 | 是否必须学习 |
|--------|---------|--------|:---:|
| 1 | `McpToolsExampleOverHttp.java` | 通过 HTTP/SSE 连接远程 MCP 服务器：看它理解"客户端连 MCP 服务 → 拿工具 → 注入 Agent"的完整步骤。 | 是 |
| 2 | `McpToolsExampleOverStdio.java` | 通过 stdio 连接本地 MCP 子进程：理解"本地进程标准输入输出作为传输通道"的方式。 | 是 |
| 3 | `Bot.java` | 声明式 AI 服务接口（`chat` 方法），作为调用 MCP 工具的 Agent 契约。 | 是 |

## 学习建议

- **先看 `McpToolsExampleOverHttp`**：理解了远程连接最常用的一种，另一个 stdio 是它的变体。
- 重点理解三个关键词的配合：**McpServer（工具在哪）→ McpClient/McpToolProvider（怎么取工具）→ AiServices（怎么把工具给 Agent）**。
- MCP 协议本身不必深究底层传输细节，知道"它把工具调用标准化了"即可。
- 实际运行需要本地启动一个 MCP 服务器（示例有配套说明，常要 `npm` 起本地服务）；如果不想搭环境，读懂代码流程也够。
