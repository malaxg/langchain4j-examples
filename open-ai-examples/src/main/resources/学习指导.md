# open-ai-examples 模块学习指导

## 模块概述

这是 **OpenAI 模型全能力集成示例**，覆盖面最全：不仅聊天，还有流式、Embedding 向量、图像生成、音频转写、函数调用（Tool）、可观测性（Listener）。当你需要"用 OpenAI 干某件具体的事"时，来这个模块找对应示例最合适。

它是 `tutorials`/`other-examples` 用到的 `OpenAiChatModel` 的"深度版本"——展示了更多模型类型和更多参数。

## 总体在教什么

- OpenAI 聊天模型的各种参数与请求方式
- 流式聊天（打字机）
- Embedding：把文本转成向量（RAG 的基础原料）
- ImageModel：生成/编辑图像
- AudioModel：语音转文字
- Function Calling：定义 `@Tool` 让模型调用 Java 方法
- 可观测性：通过 Listener 记录请求/响应，为生产监控打基础

## 学习路径（按优先级从高到低，逐一定义）

| 优先级 | Java 类 | 讲什么 | 是否必须学习 |
|--------|---------|--------|:---:|
| 1 | `OpenAiChatModelExamples.java` | **最核心**：ChatModel 的完整用法（文本、图文、请求参数、结构化输出）。编程聊天与基础功能都靠它。 | 是 |
| 2 | `OpenAiStreamingChatModelExamples.java` | 流式聊天：边生成边输出，真实聊天应用的基础。 | 是 |
| 3 | `OpenAiEmbeddingModelExamples.java` | Embedding：文本向量化，是 RAG 检索的底层依赖，必懂概念。 | 是 |
| 4 | `OpenAiFunctionCallingExamples.java` | 函数调用：`@Tool` + `@P` 定义工具，让模型调用你的方法，Agent 核心能力。 | 是 |
| 5 | `OpenAiObservabilityExamples.java` | 可观测性：ChatModelListener 监听每次请求/响应/异常，生产监控与成本计量的基础。 | 是 |
| 6 | `OpenAiImageModelExamples.java` | 图像生成（ImageModel）：出图、编辑。按需用。 | 否 |
| 7 | `OpenAiAudioModelExamples.java` | 音频转文字（AudioModel）：转写语音。按需用。 | 否 |
| 8 | `ApiKeys.java` | API Key 提供辅助类。了解即可。 | 否 |

## 学习建议

- **主线是前 5 个**：对话、流式、Embedding、函数调用、可观测性，这五项是 AI 开发高频能力。
- **图像/音频是分支**：只在做多模态产品时才需要，前期了解存在即可。
- **优先读 `OpenAiChatModelExamples`**：它把最常用能力都演示了，先吃透它。
- 需要配好 `OPENAI_API_KEY`；若用 Azure/其他厂商，可对照 `azure-open-ai-examples` 看写法差异。
