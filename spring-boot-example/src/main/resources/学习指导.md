# spring-boot-example 模块学习指导

## 模块概述

这是官方演示**如何在 Spring Boot 3 中集成 LangChain4j** 的模块。对于一个 Java 开发者转做 AI 开发，这是最贴近"生产落地"的一课：学会怎么把 AI 服务注册成 Spring Bean、用 REST 暴露接口、配工具、接监听器。它验证了 LangChain4j 能无缝融入你已有的 Spring 技术栈。

> 注意：本模块用的是 `langchain4j-spring-boot-starter`，用 Spring 配置属性（如 `spring.ai`）注入模型，风格与前面"手写 builder()"不同。这是生产项目的标准做法。

## 总体在教什么

- 用 Starter 在 Spring Boot 里装配 LangChain4j
- 把 AiService 注册为 Bean 并通过 Controller 暴露 REST 接口
- 同步聊天与流式聊天（SSE）两种接口写法
- 通过 `@Tool` 给 AI 服务加入工具
- 通过 `ChatModelListener` 监听模型调用（请求/响应/错误），做可观测性
- 低层 API（直接用 `ChatModel` Bean 而不经 AiService）

## 学习路径（按优先级从高到低，逐一定义）

| 优先级 | Java 类 | 讲什么 | 是否必须学习 |
|--------|---------|--------|:---:|
| 1 | `ExampleApplication.java` | Spring Boot 启动类，相当于应用的入口，先确认它是标准 Spring Boot 应用。 | 是 |
| 2 | `aiservice/Assistant.java` | AI 服务接口：声明 `chat` 方法（将来由框架生成实现）。 | 是 |
| 3 | `aiservice/AssistantConfiguration.java` | 配置类：声明 `ChatMemory`、`ChatModelListener` 等 `@Bean`，注入给 AI 服务。看它理解"Bean 装配"。 | 是 |
| 4 | `aiservice/AssistantController.java` | REST 控制器：`/assistant`（同步）与 `/streamingAssistant`（流式）两个接口，看前端怎么调。 | 是 |
| 5 | `aiservice/StreamingAssistant.java` | 流式 AI 服务接口：返回 `TokenStream` 的流式声明写法。 | 是 |
| 6 | `aiservice/AssistantTools.java` | `@Tool` 工具类：给 AI 加"当前时间"等工具，演示工具注入到 AI 服务。 | 是 |
| 7 | `aiservice/MyChatModelListener.java` | 模型监听器：监听每次请求/响应/错误，打印日志，是生产可观测性的基础。 | 是 |
| 8 | `lowlevel/ChatModelController.java` | 低层 API 写法：不经过 AiService，直接注入 `ChatModel` Bean 在 Controller 里调 `chat()`。 | 是 |

## 学习建议

- **先读 `AssistantConfiguration` + `Assistant` + `AssistantController` 三件套**：它们构成了"配置 → 服务 → 接口"的完整闭环，也是你日后写 Spring AI 应用的骨架。
- **对照一下 Starter 风格 vs 手写 builder 风格**：`tutorials` 里是手写 `OpenAiChatModel.builder()`，这里是配置属性注入。理解二者等价，面试常问。
- **流式接口（SSE）是加分项**：真实产品聊天都走流式，值得单独看懂。
- **Listener 是"生产必配"**：没有监控的 AI 应用等于裸奔，学完 `MyChatModelListener` 就懂了如何记录成本/延迟/报错。
- 配置项在 `src/main/resources/application.properties`，配合 `AssistantConfiguration` 一起读。
