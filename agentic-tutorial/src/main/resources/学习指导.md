# agentic-tutorial 模块学习指导

## 模块概述

这是 LangChain4j 官方**最高价值**的 AI Agent 进阶教程，用一个贯穿始终的"简历生成与招聘评审"业务场景（CV 场景），系统演示 9 种 Agent 工作流范式。它和前面所有模块最大的不同是：**不再教单个功能，而是教你怎么把多个 Agent 编排成一个完整流程**——这正是"AI Agent 开发"岗位的核心能力。

模块按 `_1` 到 `_9` 编号分目录，每个目录是一课，演示一种工作流。**务必按编号顺序学**，因为后面的课会复用前面课的技巧。

## 总体在教什么

- 基础 Agent：把 LLM 封装成可调用"能力节点"
- 顺序工作流：多个 Agent 串行执行，上一个的输出是下一个的输入
- 循环工作流：Agent 反复执行直到满足退出条件（评审→修改→再评审）
- 并行工作流：多个 Agent 同时干活，结果聚合
- 条件工作流：根据运行结果动态选择下一步分支
- 组合工作流：把多个小工作流拼装成一个大工作流
- Supervisor（主管）编排：一个"老板"Agent 调度多个子 Agent / 理解为谁该干活
- 非 AI Agent：不依赖大模型的纯逻辑节点（打分、聚合）
- Human-in-the-loop：人在流程中做决策，Agent 请求人工确认

## 学习建议

- **顺序不能乱**：`_1 → _2 → ... → _9`，每课都踩在前一课基础上。
- **先看编号示例（_1a/_2a…），接口文件随后看**：示例展示"怎么编排"，接口展示"节点如何声明"。
- **全程跟着"CV 招聘"场景走**：如果某个文件看不懂，回到它依赖的上一课找源头。
- 面试重点：**循环工作流（_3）、并行（_4）、Supervisor 编排（_7）、人机协作（_9）** 是 Agent 面试高频话题，务必理解其思想并能讲清"退出条件/聚合/调度/人工介入"各自解决什么问题。
- 辅助类（util、domain）遇到再回看，千万别在主线上卡住。
