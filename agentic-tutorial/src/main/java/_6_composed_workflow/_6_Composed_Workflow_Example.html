— 招聘团队流程（HIRING TEAM WORKFLOW）—
类型化顺序工作流 HiringTeamWorkflow sequenceBuilder(HiringTeamWorkflow.class).subAgents(parallelReviewWorkflow, decisionWorkflow)
并行工作流 parallelReviewWorkflow parallelBuilder().subAgents(hrCvReviewer, managerCvReviewer, teamMemberCvReviewer).executor(3线程)
∥ 三个评审并发运行

条件工作流 decisionWorkflow conditionalBuilder().subAgents(平均分>=0.8, interviewOrganizer).subAgents(平均分<0.8, emailAssistant)

结束
运行完毕
要点：所有 Agent 底层都是同一个 Agent 对象，因此天然可组合、可嵌套（图中外层工作流完整包含内层工作流）。无论嵌套多少层，所有参数都存放在同一个共享的 AgenticScope 中。注意保持参数名称唯一，以免无意覆盖。
