流程图：_9b_HumanInTheLoop_Chatbot_With_Memory

来回循环 + 人机协作（带记忆）：AI 提议会议时间 → 人类回答 → 再提议，直到达成一致

开始
main() 启动
设置日志级别 PRETTY, 300
模型
定义底层模型 CHAT_MODEL
ChatModelProvider.createChatModel()
子 Agent
MeetingProposer（会议提议者）
agentBuilder(MeetingProposer.class)
.chatMemoryProvider（记忆最多 15 条，记住已提议时段）
输出键：proposal
AiService
DecisionsReachedService
判断双方是否已达成一致（简单任务，可选用小型本地模型）
人机协作 Agent humanInTheLoop humanInTheLoopBuilder().description("向用户索取输入的智能体").outputKey("candidateAnswer").async(true)
responseProvider
控制台交互
打印提议（readState("request")），等待人类输入
.async(true)：等待输入时不阻塞整个程序
循环工作流 schedulingLoop（安排会议循环） loopBuilder().subAgents(agentSequence).outputKey("proposalAndAnswer").maxIterations(5)
顺序组合（每次循环只检查一次退出条件） agentSequence sequenceBuilder().subAgents(proposer, humanInTheLoop).output({proposal, candidateAnswer})

MeetingProposer

步骤 2
HumanInTheLoop

退出条件（AiService 判定）
人类确认有空了吗？
decisionService.isDecisionReached(proposal, response)
确认 → 退出循环；未确认 → 回到循环起点继续下一轮提议（最多 5 轮）
输入参数

meetingTopic = "现场参观"
candidateAnswer = "hi"（需预存在作用域，因 MeetingProposer 把它作为输入）
memoryId = "user-1234"（不提供则提议者无法记住已提议内容）
执行
invoke(Map 传参)
schedulingLoop.invoke(input)
循环：提议 → 人类回答 → 检查退出条件 → …（最多 5 轮）
输出
=== 结果：最后一次提议与回答 ===
打印 lastProposalAndAnswer
结束
运行完毕
循环持续到人类确认有空，或 5 轮后强制结束
要点："来回循环 + 人机协作"：AI 提议 → 人类回答 → 再提议，直到达到结束目标，之后工作流的其余部分才继续执行。把两个 Agent 打包成顺序组合作为整体交给循环，以便每个循环只检查一次退出条件。
